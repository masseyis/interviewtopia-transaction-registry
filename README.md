# Interviewtopia Transaction Registry

Static, read-only transaction terms used by the Interviewtopia Completion Service assessment.

- Swagger UI: <https://masseyis.github.io/interviewtopia-transaction-registry/docs/>
- OpenAPI definition: <https://masseyis.github.io/interviewtopia-transaction-registry/openapi.yaml>
- Example transaction: <https://masseyis.github.io/interviewtopia-transaction-registry/transactions/sale-123.json>

The interviewer supplies this service after the candidate has explored the deliberately underspecified business brief. It is public so candidates can integrate without credentials; all records are synthetic.
